# 101-main-ui 测试用例（test-cases.md）

> 与 `spec.md` 验收场景对应。真机（Redmi，Android 12+）验证为主。

## TC1 应用栏目四态
- TC1-1 S1：清空 connectPort 后进「应用」→ 只显示"请配置端口+去设置"；截图。
- TC1-2 S2：已配端口、未建会话 → 居中「连接并建立会话」；截图。
- TC1-3 连接失败（乱端口）→ 提示失败，不崩溃。
- TC1-4 S3：连接成功后 → 图标网格（含已安装可启动 App）。
- TC1-5 S4：点某 App → 呈现区域显示画帧，顶栏显示 App 名，右上角 4 按钮可见。
- TC1-6 嵌入触摸：在嵌入区域点按 → 被托管 App 响应（画帧变化或到设置页）。

## TC2 呈现切换与关闭
- TC2-1 嵌入→全屏：画帧出现在全屏 Activity，触摸可用。
- TC2-2 全屏→浮窗：浮窗出现，能拖动、点击回写、✕ 关闭。
- TC2-3 全屏/浮窗控制「嵌入」→ 回到主界面嵌入态，会话不断。
- TC2-4 S4「关闭」→ 回到 S3 网格，hostedApp 置空。
- TC2-5 浮窗未授权时 → 引导授予"显示在其他应用上层"。

## TC3 自动化互斥执行/停止
- TC3-1 复用 S1/S2 判定。
- TC3-2 列表项：App 图标+名称、时间设置、启用开关；启用项右侧有播放+编辑。
- TC3-3 点 A 播放 → A 行显示停止，B 行播放/停止隐藏；A.runCount 增加。
- TC3-4 点 A 停止 → A、B 行按钮恢复。
- TC3-5 任一时刻只有一个运行态（运行中再禁止触发其它项）。

## TC4 编辑表单
- TC4-1 新建/编辑：名称/App/脚本/启用/立即·间隔·cron 字段齐全。
- TC4-2 cron 合法保存 → 列表显示新时间；非法 cron → 不保存并提示。
- TC4-3 保存后 TaskStore 落盘（重启 App 仍在）。
- TC4-4 编辑为停用 → 调度器取消原闹钟（`task_nextRunAt` 不再推进）。

## TC5 设置栏目
- TC5-1 端口编辑保存 → connectPort 变化，回「应用」从 S1 变 S2。
- TC5-2 token 保存 → 服务端鉴权生效（带/不带 token 请求 /status 差异）。
- TC5-3 分辨率默认等于当前屏；改后提示"需重建会话"，下次连接用新分辨率。
- TC5-4 无障碍：显示当前启用状态；按钮跳转系统设置。

## TC6 返回转发
- TC6-1 应用栏目 S4 点系统返回 → 被托管 App 收到返回（画帧变化），本 App 不退出。
- TC6-2 全屏中点返回 → 转发给被托管 App。
- TC6-3 浮窗激活时主界面返回 → 转发给被托管 App。
- TC6-4 设置在栏目（无呈现）→ 常规返回可退出。

## TC7 健壮性 & 回归
- TC7-1 会话未就绪的任何操作不崩溃，有提示。
- TC7-2 既有 REST `GET /status`、`/apps` 仍可用（回归）。
- TC7-3 构建 `assembleDebug` 通过；安装运行无异常日志。

## 记录格式
每个通过项：`[PASS] TCx-x 描述`；失败项：`[FAIL] …（现象/日志）`。
