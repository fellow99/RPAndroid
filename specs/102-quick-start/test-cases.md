# 102-quick-start 测试用例（test-cases.md）

> 与 `spec.md` 验收场景对应。真机（新装本 App）验证为主；不记录真实 IP/端口/配对码。

## TC1 全新设备首启向导触发
- TC1-1 全新安装（`paired=false, connectPort=0`）→ 打开「应用」→ 显示配对向导（而非"请配置端口"）；截图。
- TC1-2 同状态下打开「自动化」→ 同样显示向导；截图。
- TC1-3 向导 Step1–3 文案为无术语大白话（不出现 adb/shell/RSA），按钮可跳「关于手机」「开发者选项」。
- TC1-4 步骤间「上一步/下一步」可用，返回不崩溃。

## TC2 配对成功全链路（真机 Xiaomi/Android16，2026-11-09 已执行）
- [x] TC2-1 开开发者选项/USB 调试/无线调试后，在系统「使用配对码配对设备」读 6 位码，填入 Step4 → 「完成配对」。
- [x] TC2-2 配对成功 → 设备「已配对设备」出现本 App key（mika@…）；自动建会话在本机 mDNS 不可靠，新版改：配对成功即 paired=true，连接失败给手动连接端口重试（引导顶部端口）。
- [ ] TC2-3 完成后 `ServerConfig.paired=true` 且 `connectPort!=0`（重启 App 复验）。
- [ ] TC2-4 重启后重进「应用」→ 不再弹向导（S2"连接并建立会话"或已自动恢复会话）。

## TC3 配对失败与重试（真机已执行）
- [x] TC3-1 填错 6 位码 → 提示"配不上 + 怎么办"，不崩溃，可重填重试。
- [x] TC3-2 配对码窗口超时 → 提示回去再点一次「使用配对码配对设备」；实测窗口约 20 秒、端口随重开变化。
- [x] TC3-3 自动发现端口失败 → 显示可选手动端口输入（实测 mDNS『没有自动找到』，手动配对端口成功）。

## TC4 自动打开无线调试
- TC4-1 配对 + 会话成功后，读系统 `adb_wifi_enabled` 为 1（`settings get global adb_wifi_enabled`）。
- TC4-2 手动关掉无线调试后再起会话 → 重新被写为 1（尽力而为，允许失败）。

## TC5 旧用户不回归
- [x] TC5-1 预置 `connectPort`（模拟已配置用户升级）→ 打开两栏 → 不弹向导，走既有 S1/S2。
- [x] TC5-2 `paired=true` 且未建会话 → 不再要求配端口，显示「连接并建立会话」（S2 自动发现），不进向导。
